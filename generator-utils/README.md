# onecx-generator-utils

Shared utility functions used by the OneCX `@onecx/angular-generator` and
`@onecx/react-generator` code generators.

This library was generated with [Nx](https://nx.dev).

## Building

Run `nx build generator-utils` to build the library.

## Running unit tests

Run `nx test generator-utils` to execute the unit tests via [Jest](https://jestjs.io).
